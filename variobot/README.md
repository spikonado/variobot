# variobot

This package contains code relevant to controlling VarioBot in real life.

Use `robot_launch.yaml` to launch the robot:

```bash
ros2 launch variobot robot_launch.yaml
```

## Purpose of each directory

- [`config`](config/): Contains config files that are used by various nodes.
- [`launch`](launch/): Contains launch files used to launch the various systems/nodes related to the robot.
